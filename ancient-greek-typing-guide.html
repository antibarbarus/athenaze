Как печатать по-древнегречески

Для древнегреческого лучше всего использовать поли-тоническую греческую раскладку (Greek Polytonic). Она позволяет вводить не только буквы, но и придыхания, три вида ударения, подписную йоту и диэрезис.

Главное правило: сначала включите Greek Polytonic, а затем набирайте греческий текст обычной клавиатурой. Диакритические знаки вводятся с помощью так называемых «мёртвых клавиш».

1. macOS

  1. Откройте System Settings → Keyboard.
  2. В разделе Text Input нажмите Edit….
  3. Нажмите + и найдите Greek.
  4. Добавьте раскладку Greek Polytonic.
  5. Переключайтесь между языками через меню ввода или сочетанием Control + Space.
Полезно включить Keyboard Viewer. Он показывает, какие символы появятся при нажатии обычных клавиш, Shift и Option. Это самый надёжный способ быстро освоить диакритику именно на вашей физической клавиатуре.

2. Windows

  1. Откройте Settings → Time & language → Language & region.
  2. Добавьте язык Greek, если его ещё нет.
  3. Откройте параметры греческого языка и добавьте клавиатуру Greek Polytonic.
  4. Переключайтесь между раскладками сочетанием Win + Space.
Если вы не помните расположение диакритик, откройте экранную клавиатуру Windows. На полифонической раскладке акценты и придыхания работают как «мёртвые клавиши»: сначала вводится знак, затем гласная.

5. Сочетания клавиш для диакритики

Ниже указаны клавиши для стандартной раскладки Greek Polytonic на клавиатуре с расположением знаков как у US/QWERTY. Сначала нажмите клавишу диакритики, затем гласную.

macOS: Greek – Polytonic

Диакритика Клавиша Пример
острое ударение ; + гласная ; + a → ά
тяжёлое ударение ] + гласная ] + a → ὰ
облечённое ударение [ + гласная [ + a → ᾶ
тонкое придыхание ' + гласная ' + a → ἀ
густое придыхание Shift + ', затем гласная " + a → ἁ
подписная йота Shift + [, затем α / η / ω { + a → ᾳ
диэрезис Shift + ;, затем ι / υ : + i → ϊ
На Mac диакритики удобно комбинировать последовательно. Например: ' + ; + a → ἄ; Shift+' + [ + h → ἧ; ' + [ + Shift+[ + v → ᾧ. Порядок нескольких мёртвых клавиш обычно несущественен: главное нажать их до гласной.

Windows: Greek Polytonic

В стандартной раскладке Windows для простых знаков используются те же удобные клавиши, но для некоторых сочетаний «придыхание + ударение» предусмотрена отдельная мёртвая клавиша.

тяжёлое ударение ] + гласная ] + a → ὰ

тонкое придыхание ' + гласная ' + a → ἀ
густое придыхание Shift + ', затем гласная " + a → ἁ
подписная йота Shift + [, затем α / η / ω { + a → ᾳ
диэрезис Shift + ;, затем ι / υ : + i → ϊ

6. Как набирать букву с несколькими знаками

В полифонической раскладке несколько диакритик можно соединять на одной гласной. На Mac их особенно удобно набирать по отдельности перед буквой; в Windows для многих частых комбинаций предусмотрены отдельные мёртвые клавиши.

Нужно получить Из чего состоит
ἄ тонкое придыхание + острое ударение + α
ἧ густое придыхание + облечённое ударение + η
ᾧ тонкое придыхание + облечённое ударение + подписная йота + ω

10. Если что-то не получается

  • Проверьте, что выбрана именно Greek Polytonic, а не обычная Greek.
  • Откройте Keyboard Viewer / экранную клавиатуру и найдите нужный знак визуально.
  • Если знак появляется отдельно от буквы, попробуйте сначала диакритику, затем гласную.
  • Используйте Unicode-шрифт. Современные браузеры, Word, Pages и Google Docs обычно подходят без дополнительной настройки.
  • Не заменяйте греческий вопросительный знак ; латинским ?.
