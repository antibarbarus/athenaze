Μελέτημα 3.13

Выберите прилагательное, правильно согласованное с существительным

В каждом пункте только одна из трёх форм прилагательного согласована правильно. Нажмите на неё.
1. τοῦ ( ἀργούς, ἀργοί, ἀργοῦ ) δούλου
2. οἱ ( ὡραῖοι, ὡραίῳ, ὡραίοις ) καρποί
3. τῷ ( ἱκανοί, ἱκανῷ, ἱκανοῖς ) δείπνῳ
4. τὸ ( καλός, καλούς, καλόν ) δένδρον
5. τὸν ( κακός, κακέ, κακόν ) υἱόν
6. ὁ ( χαλεπός, χαλεποί, χαλεπόν ) ἄροτος

1. ἀργοῦ — gen. sg. masc., согласуется с δούλου.

2. ὡραῖοι — nom. pl. masc., согласуется с καρποί.

3. ἱκανῷ — dat. sg. neut., согласуется с δείπνῳ.

4. καλόν — nom./acc. sg. neut.; здесь acc. sg., согласуется с δένδρον.

5. κακόν — acc. sg. masc., согласуется с υἱόν.

6. χαλεπός — nom. sg. masc., согласуется с ἄροτος.
