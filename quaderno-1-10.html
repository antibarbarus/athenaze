Quaderno 1.10

Выберите единственный вариант, подходящий по смыслу, затем переведите предложение

В каждом предложении из трёх предложенных вариантов только один подходит по смыслу. Отметьте его, затем переведите всё предложение на русский язык.

Выбор варианта проверяется автоматически. Для перевода возможны разные хорошие формулировки, поэтому он сверяется с образцом вручную.
