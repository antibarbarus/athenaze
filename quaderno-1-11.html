Quaderno 1.11

Соедините части предложений, затем переведите их

Для каждого выражения слева выберите подходящее продолжение справа. Затем переведите получившееся предложение на русский язык.

Продолжения можно использовать только по одному разу по смыслу. Перевод проверяется по образцу вручную.
